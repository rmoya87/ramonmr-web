# ramonmr-web

Código propio de ramonmr.com. WordPress y la base de datos siguen en IONOS.

- `wp-content/themes/ohio-child/`: functions.php y style.css actuales, sin cambios de funcionamiento.
- `docs/desarrollo.md`: proceso de cambios y pendientes funcionales.
- `.gitignore`: exclusiones para evitar subir credenciales, datos y dependencias.

El tema hijo necesita Ohio instalado por separado. Su cabecera actual usa el nombre "Upepo" y `Template: ohio`; se conserva tal como está en producción.

No se incluyen WordPress, plugins de terceros o comerciales, base de datos, medios, cachés, copias de seguridad, screenshot comercial ni credenciales. Los diseños del constructor guardados en la base de datos no están aquí.

Este paquete no incluye automatización de publicación. Subirlo al repositorio no cambia la web en IONOS por sí solo.
